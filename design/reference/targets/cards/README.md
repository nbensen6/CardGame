# Card references

Nick's own pictures of what the cards should look like. Drop them in this folder.

- `style.png` (or any name starting `style`): the look for every card.
- A file named after a card (`leap.png`, `tongue-snap.png`): the look for that one card.

For card faces and frames these outrank `../TARGET-UI.png`. The grader opens them beside every frame that touches cards.
