# /input — pointer-first input abstraction

Single-pointer input only (CLAUDE.md §5). A mouse click == a finger tap.
No action may *require* right-click, hover, or a keyboard shortcut as its only
path. No hover-only information — card details/tooltips/keywords must be
reachable by tap/click (e.g. tap-to-inspect).

Keyboard/mouse extras are fine as optional accelerators, never the only path.
